## Iteration 1 - US-079: install-weekly creates and loads the plist
- What I did: Added `praxis install-weekly` subcommand backed by `praxis/cli/install_weekly.py`. Generates ~/Library/LaunchAgents/co.praxis.weekly.plist (Label=co.praxis.weekly) using `schedule.day/hour/minute` from ~/.praxis/config.toml and loads it with `launchctl load -w`. Idempotent re-runs unload first. CLI exits 4 with stderr message on launchctl failure (InstallWeeklyError surfacing returncode + stderr).
- Files changed: praxis/cli/install_weekly.py (new), praxis/cli/__main__.py (cmd_install_weekly + subparser), tests/test_install_weekly.py (new, 12 tests), scripts/ralph/feature/macos-launch-agent/prd.json (passes=true), scripts/ralph/progress.txt (this entry).
- Verification: `uv run pytest -q` -> 1024 passed (12 new + 1012 existing). `uv run pyright praxis/cli/install_weekly.py` -> 0 errors. The 3 pre-existing pyright errors on cli/__main__.py (WeeklyRunSummary vs RunSummary) are unchanged before/after this commit; confirmed by git stash + pyright comparison.
