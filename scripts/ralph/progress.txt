## Iteration 8 - US-011: Per-week aggregation helper
- What I did: Added `aggregate_for_week(profile_store, week_iso) -> AugAutoWeekSummary` to `praxis/behavior/aug_auto.py`, plus the new `AugAutoWeekSummary` frozen dataclass and the `AUG_AUTO_BUCKETS` tuple (the canonical bucket ordering: augmentation, automation, mixed, unclassified). The helper iterates `profile_store.load_session_scores()` (default dedup to highest-pass per session is correct because the classifier writes the same value on every pass), filters rows whose `started_at` falls in the target ISO week via a `_row_week_iso` helper, and buckets each row by `aug_auto_classification` -- NULL or any unknown literal goes into 'unclassified'. Returns counts, shares (totals / total when total>0; all-zero when total==0), total, and `classifier_unavailable` (True iff total>=1 AND every row is unclassified).
