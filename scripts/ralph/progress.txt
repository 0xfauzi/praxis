  - The renderer lives in praxis/reports/digest_html.py and is a pure function `render(digest: WeeklyDigest) -> str`. ## Iteration 2 - US-062: Section order per 6.1
- What I did: Added six frozen panel dataclasses (Trajectory, MomentPanel, CostLedger, TaskRow, DimRow, FollowUpPanel) plus a `one_thing_to_try: str` field on WeeklyDigest, all optional with sensible defaults. The render() now walks a fixed seven-section list in spec section 6.1 order (trajectory -> moment -> cost ledger -> task breakdown -> dimensions -> follow-up -> next-week-try) and emits stable HTML id anchors so the document order is test-anchorable. The masthead carries only the week title and generation date - no /10 above the fold. Added 14 tests covering the section order, the masthead-no-/10 contract, populated-vs-placeholder paths, and a regression check that US-061 self-containment still holds with new sections in play.
