A rule must stay correct. Select a component to see its rules.

Each rule gives its assurance level and its freshness.

  1. A praxis hook exits 0 on every input, prints nothing to stdout, and never changes the output or exit code of the agent (AGENTS.md, invariant 7; src/praxis/hooks.py docstring).examined · current
  2. Only src/praxis/store.py contains INSERT statements for the ledger tables. The derived-writes-only-in-store pre-commit hook refuses them in other modules (AGENTS.md, invariant 2; .pre-commit-config.yaml).examined · current
  3. The ledger stores hashes, counts, and identifiers. It never stores a line of a file, a prompt, or a tool input or response (AGENTS.md, invariant 5; src/praxis/store.py docstring; docs/design/01-recorder.md, What is stored).examined · current
  4. Without a baseline, the human, pre-existing, and reverted counts are NULL and the coverage is no_baseline. A CHECK constraint keeps the two together (AGENTS.md, invariant 4; src/praxis/store.py:93-96).examined · current
  5. Attribution matches multisets of line hashes: two identical lines are two lines, and an agent line that the diff no longer holds is ambiguous, not human (AGENTS.md, invariant 13; src/praxis/gitdiff.py docstring).examined · current
  6. praxis setup PRINTS the hook block. With --apply or --remove, it writes exactly one named file after an interactive yes, and it refuses when stdin is not a terminal (AGENTS.md, invariant 8; src/praxis/install.py:189-197).examined · current
  7. praxis doctor opens the ledger in SQLite read-only mode and never creates it (src/praxis/doctor.py docstring and line 61).examined · current
  8. The dependencies list in pyproject.toml is empty. Praxis uses the Python standard library only (AGENTS.md, invariant 6; pyproject.toml line 15).examined · current
  9. Code that must run for a measurement runs in a scratch clone under $PRAXIS_HOME that the caller deletes. The working tree and .git of the owner are never written (AGENTS.md, invariant 5; src/praxis/extract.py scratch_clone docstring).examined · current
  10. Probe items are scored by deterministic, versioned extractors. No project test is a score or an item source (AGENTS.md, invariant 9; src/praxis/extract.py EXTRACTOR_VERSION).examined · current
  11. The attached-agent check looks for claude or codex processes with a working directory in the repository. Where /proc is missing, it counts any such process anywhere (AGENTS.md, invariant 9; src/praxis/unassisted.py docstring and attached_agents).examined · current
